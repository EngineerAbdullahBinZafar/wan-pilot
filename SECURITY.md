# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or execution sandbox escape in Wan-Video Pilot, please report it responsibly by contacting the maintainer via GitHub issues or email.

All reports will be acknowledged within 48 hours, and a patch will be prepared before public disclosure.
