# Pull Request: Fix Image Conditioning EXIF Orientation Inversion (Fixes #415)

## Description
When loading user-uploaded conditioning images for Image-to-Video (I2V) in `generate.py`, standard `Image.open()` ignores EXIF orientation metadata tags (Orientation 1–8). Consequently, mobile smartphone photos shot in portrait or rotated angles are loaded rotated 90°/180°/270° or mirrored, causing deformed video generation.

## Changes
- Wrapped conditioning image loading with `PIL.ImageOps.exif_transpose()`.
- Added dimension rounding to 16-pixel spatial patch boundaries to prevent DiT spatial embedding assertion crashes.

## Testing & Verification
- Tested with synthetic JPEG images across all 8 standard EXIF orientation codes.
- Verified that pixels are properly oriented prior to VAE tensor encoding.
